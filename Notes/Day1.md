# 4. Python Interpreter

Python can run in two ways:

### Interactive Mode

```python
>>> print("Hello World")
```

Output:

```python
Hello World
```

### Script Mode

Create:

```python
main.py
```

Code:

```python
print("Hello World")
```

Run:

```bash
python main.py
```

# 6. Variables

Variables store data.

Example:

```python
name = "Gaurav"
age = 21
```

Print Variables:

```python
print(name)
print(age)
```

Output:

```python
Gaurav
21
```

---

# 7. Input from User

Example:

```python
name = input("Enter your name: ")
print(name)
```

Output:

```python
Enter your name: Gaurav
Gaurav
```

---

# 8. Output

Simple Output:

```python
print("Welcome to Python")
```

Output:

```python
Welcome to Python
```

Multiple Values:

```python
name = "Gaurav"
age = 21

print(name, age)
```

Output:

```python
Gaurav 21
```

# 🛠 Mini Project 2 - Age Calculator

### Problem

Calculate age from birth year.

### Code

```python
birth_year = int(input("Enter Birth Year: "))

current_year = 2026

age = current_year - birth_year

print("Your age is:", age)
```

### Output

```python
Enter Birth Year: 2004

Your age is: 22
```

## Q4. Difference Between Input and Output?

Input:

```python

```

Used to take data from the user.

Output:

```python

```

Used to display data.
