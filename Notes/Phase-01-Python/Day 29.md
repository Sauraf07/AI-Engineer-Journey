The Personal Assistant should include the following features:

## ✅ Calculator

- Addition
- Subtraction

- Division

## ✅ Notes Manager

Allow users to:

- Add Notes

- Save Notes

Example:

```text

```

## ✅ Weather Information

Using the OpenWeather API (or any weather API):

- Enter city
- View temperature
- Humidity
- Weather condition

```text
City: Indore

Temperature: 31°C

Humidity: 52%

Condition: Clear Sky
```

Display:

```

```

Allow the user to exit safely.

# 🎤 Interview Questions

## Beginner

### 1. Why did you build this project?

To practice Python fundamentals by integrating multiple concepts into a real-world application.

---

### 2. Which Python concepts are used?

- Functions
- Loops
- Conditional Statements
- File Handling
- Exception Handling
- Modules
- APIs

---

### 3. Why did you divide the project into functions?

To improve readability, maintainability, and code reusability.

---

### 4. How are notes stored?

Using a text file (`notes.txt`) with Python's file handling.

---

### 5. Which module is used to display the current date and time?

The `datetime` module.

---

## Intermediate

### 6. Why use exception handling in this project?

To prevent the application from crashing due to invalid user input or API errors.

---

### 7. How would you improve this project?

- Add a graphical interface
- Store notes in a database
- Add authentication
- Implement cloud synchronization

---

### 8. Why is modular programming important?

It makes code easier to test, maintain, and reuse.

---

### 9. Which API can be used for weather information?

The OpenWeather API.

---

### 10. What is the advantage of using APIs?

They allow applications to retrieve and exchange real-time data with external services.
