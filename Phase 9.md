# Day 3 — ReAct Framework

## Topics

ReAct =

Reason + Act

## Learn

Thought
Action
Observation

Example:

Thought:
Need weather.

Action:
Call Weather Tool.

Observation:
30°C

Final Answer.

By the end of Phase 9, you should be able to:

- Build AI Agents from scratch
- Use LangGraph professionally
- Create Multi-Agent Systems
- Build Agentic RAG Applications
- Implement Memory Systems
- Build Production Agent Workflows
